# 夹爪DM4310的PID整定

控制的是达妙DM4310，走CAN2，电机ID是1。

用的是电机的速度位置模式，给目标角度和速度上限，是角度控制。PID是电机驱动器里面自带的，我做的是通过CAN改它的增益寄存器（0x19到0x1C），位置环KP整定到94，速度上限4 rad/s。

用到队里BSP的DM_J4310.h、Motor.h、Task_Can.h，反馈是在User_CAN.c里0x11那帧进来的，BSP不在仓库里。

文件就两个：Gripper_Test.c是测试任务本体，使能、给目标角度、自动开合、读写参数都在里面；Gripper_Test.h是调试时要看的那些变量的声明。
